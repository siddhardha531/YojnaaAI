📌 Project Overview

YojanaAI is an AI-powered platform designed to help Indian citizens discover government welfare schemes and scholarships easily. It helps users understand scheme details, check eligibility, explore benefits, and get answers to their questions using Artificial Intelligence.

The platform uses Google Gemini AI and Retrieval-Augmented Generation (RAG) to provide context-aware responses and simplify access to government scheme information.

🎯 Objectives

Make government schemes easily accessible to citizens.

Simplify the process of finding relevant government schemes.

Help users understand eligibility criteria and benefits.

Provide AI-powered assistance for scheme-related queries.

Extract useful information from government scheme PDF documents.

✨ Key Features

Government Scheme Discovery – Explore Central and State Government schemes.

Eligibility Checker – Check eligibility based on user information and scheme criteria.

AI-Powered Assistant – Ask questions in natural language and receive AI-generated responses.

RAG-Based Question Answering – Retrieve relevant scheme information to generate context-aware answers.

PDF Document Analysis – Upload government scheme PDFs and extract important information.

Multi-Document Consolidation – Combine information extracted from multiple scheme documents.

Saved Schemes – Save and access useful schemes.

User Dashboard – Manage user information and personal documents.

Admin Dashboard – Manage government scheme information and review extracted scheme details.

🤖 AI Integration

YojanaAI integrates Google Gemini AI to support intelligent question answering and government scheme document analysis.

The RAG architecture retrieves relevant information from available scheme data and documents before generating responses. This helps provide answers grounded in the retrieved information.

🔐 Security

API keys are configured through environment variables.

Sensitive configuration files should not be uploaded to GitHub.

User and administrator authentication are supported.

Administrator access is restricted through role-based authorization.

🚀 Future Enhancements

Support for multiple Indian languages.

Voice-based interaction.

Improved government scheme recommendations.

Integration with additional official government data sources.

Enhanced document understanding and information retrieval.

🎯 Expected Impact

YojanaAI aims to reduce the difficulty citizens face when searching for government welfare schemes by bringing scheme discovery, eligibility checking, AI assistance, and document analysis together in one platform.
